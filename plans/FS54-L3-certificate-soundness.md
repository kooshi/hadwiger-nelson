# Why the level-3 certificate proves the bound

*The one page a reviewer needs. It is self-contained: it assumes no acquaintance with this repository, cites nothing
of ours in the argument, and its only claim is that the mechanical checks in `tools/fs54_l3_cert_check.py` imply the
sentence the certificate file states. Written for FS-54, 2026-09-16, in the shape of
`plans/FS50-certificate-soundness.md` (the triple-level page, which this one extends by one level). The companion
objects are the certificate `data/fs54/cert-q27-l3-N141.json`, the checker `tools/fs54_l3_cert_check.py` (standard
library, exact arithmetic), and the producer `tools/fs54_l3_cert_round.py` (untrusted: a floating-point solver
proposes, exact arithmetic disposes).*

## 0. The claim

Fix a prime power `q ≡ 3 (mod 4)`, with the field `𝔽_q` named by an explicit irreducible modulus when `q` is not
prime (at `q = 27`, `𝔽₂₇ = 𝔽₃[t]/(t³ − t − 1)`). Write `V = 𝔽_q²` for the plane, `n = q² = |V|`, and
`Q(x, y) = x² + y²` for the **quadrance** of a vector, computed in `𝔽_q`. Two points are **adjacent** when their
difference has quadrance 1; a set `S ⊆ V` is **independent** when no two of its points are adjacent; `α` is the
largest size of an independent set.

> **The claim a certificate makes.** Every independent set has at most `N` points, for an explicit rational `N`.
> Since a number of points is an integer, `α ≤ ⌊N⌋`.

Nothing below is new mathematics. It is the level-3 relaxation of Gvozdenović, Laurent and Vallentin (*Block-diagonal
semidefinite programming hierarchies for 0/1 programming*, Oper. Res. Lett. 37 (2009)) — moment matrices localised at a
point or a pair of points, every sign pattern — in Schrijver's normalisation (divide by the size of the set, so that
the objective is linear), written out for the graph above in the one form a stranger can check: an identity between two
polynomials of degree one in finitely many unknowns, plus the positive semidefiniteness of rational matrices given as
Gram factors.

**The consequence at 27.** The certificate proves `N = 1415933445295268663 / 10¹⁶ ≈ 141.5933`, so
`α(UD(𝔽₂₇, 2)) ≤ 141`. A proper colouring with five colours would have a colour class of at least `⌈729/5⌉ = 146`
points, and every colour class is independent; so **the plane over `𝔽₂₇` is not five-colourable**.

## 1. What a set carries

Let `S` be a nonempty independent set of size `s`. For a finite set `T ⊆ V` put

    N_S(T) = #{ z ∈ V : z + T ⊆ S },

the number of translates of `T` lying inside `S`. (`T` is a *set*: `{0, u, u}` is `{0, u}`.) Five facts, each
immediate:

| | fact | why |
|---|---|---|
| F1 | `N_S({p}) = s` for a single point `p` | `z + p ∈ S` for exactly `s` values of `z` |
| F2 | `N_S(T) = 0` if `T` contains two adjacent points | a translate of an edge is an edge, and `S` has none |
| F3 | `0 ≤ N_S(T) ≤ s` for nonempty `T` | `z + T ⊆ S` implies `z + t ∈ S` for any `t ∈ T`, and F1 |
| F4 | `Σ_{u ∈ V} N_S({0, u}) = s²` | swap the sums: `Σ_u #{z ∈ S : z + u ∈ S} = Σ_{z ∈ S} #{u : z + u ∈ S} = s · s` |
| F5 | `N_{γS}(γT) = N_S(T)` for every `γ(z) = g(z) + c` with `g` an additive bijection | `z + gT + c ⊆ gS + c` iff `z + gT ⊆ gS` iff `g⁻¹(z) + T ⊆ S` (additivity), and `z ↦ g⁻¹z` is a bijection |

**The anchored matrices.** Choose at most two distinct **anchor** points `a₁, a₂ ∈ V`, each with a sign `+` or `−`, and
write `[P]⁺ = [P]` and `[P]⁻ = 1 − [P]` for the indicator of a statement. For `z ∈ V` let `ξ^z ∈ {0,1}^V` be the vector
`ξ^z[u] = [z + u ∈ S]`, and put

    A_S = (1/s) · Σ_{z ∈ V}  Π_i [z + a_i ∈ S]^{σ_i} · ξ^z (ξ^z)ᵀ .

| | fact | why |
|---|---|---|
| F6 | `A_S ⪰ 0` | a sum of matrices `x xᵀ` with weights 0 or 1 |
| F7 | `A_S[u, w] = Σ_{B ⊆ negatives} (−1)^{|B|} · N_S(positives ∪ B ∪ {u, w}) / s` | expand each `1 − [·]`; a product of indicators `[z + x ∈ S]` over `x` in a set `X` is `[z + X ⊆ S]` |

With two anchors the sets in F7 have at most four points. **F4 is the one that carries the argument**: the size of
the set is a linear function of the counts.

## 2. Averaging over the symmetries, and the unknowns

Let `G₀` be the group of permutations of `V` generated by

* the rotations `(x, y) ↦ (ax − by, bx + ay)`, one for each point `(a, b)` of the unit circle `Q = 1`;
* the reflection `(x, y) ↦ (x, −y)`;
* the Frobenius `(x, y) ↦ (x^p, y^p)`, `p` the characteristic.

Each generator is an additive bijection of `V` preserving the unit circle, so every element of `G₀` is, and every map
`γ(z) = g(z) + c` (`g ∈ G₀`, `c ∈ V`) preserves adjacency. Write `Γ` for the group of these maps. Then `γS` is again an
independent set of size `s`, and we average:

    ȳ(T) = (1/|Γ|) · Σ_{γ ∈ Γ}  N_{γS}(T) / s .

| | property | why |
|---|---|---|
| Y1 | `ȳ(γT) = ȳ(T)` for `γ ∈ Γ` | F5 applied to `γ⁻¹ ∈ Γ` turns `N_{γ'S}(γT)` into `N_{γ⁻¹γ'S}(T)`; reindex the sum over the group |
| Y2 | `ȳ({p}) = 1`; `ȳ(T) = 0` if `T` has two adjacent points; `0 ≤ ȳ(T) ≤ 1` otherwise | F1, F2, F3 for each `γS` |
| Y3 | `Σ_{u ∈ V} ȳ({0, u}) = s` | F4 for each `γS` |
| Y4 | for any anchors and signs, the matrix `Ā[u,w] = Σ_B (−1)^{|B|} ȳ(positives ∪ B ∪ {u,w})` is positive semidefinite | by F7 it is the average over `Γ` of the matrices `A_{γS}`, each PSD by F6 |

**The unknowns.** The **canonical form** of a set `T` of two to four distinct points is the least, as a sorted tuple,
of the nonzero points of `g(T − t)`, over `t ∈ T` and `g ∈ G₀`. The one property soundness needs is that
**the canonical form, with the origin added, is `γ(T)` for some `γ ∈ Γ`** (namely `z ↦ g(z − t)`), so by Y1 two sets
with the same canonical form have the same `ȳ`. (That two sets in one `Γ`-orbit get the *same* form is needed only
for the identity below to be findable; if it failed, a certificate would be refused, never wrongly accepted.)

Index unknowns `y_K` by the canonical forms `K` of independent sets of two to four points. For anchors and signs,
let `A(y)` be the matrix whose `(u, w)` entry is F7's expansion with each `N/s` replaced by

* `1` if the set is a single point, `0` if it contains two adjacent points, and `y_K` for its canonical form `K`
  otherwise,

and let `Obj(y) = Σ_{u ∈ V} (the same replacement for {0, u})`. Both are affine in `y`. **At the vector `ȳ_S` with
`(ȳ_S)_K = ȳ(T)` for any `T` of form `K`**, Y2 says the replacement is exact, so `A(ȳ_S) = Ā` is PSD (Y4) and
`Obj(ȳ_S) = s` (Y3); and `0 ≤ (ȳ_S)_K ≤ 1` (Y2).

## 3. The certificate, and the lines that make it work

A **certificate for `N`** is: a rational `N ≥ 1`; a list of matrices, each named by its anchors and signs and each
presented as `Z = Σ_b U_b Z_b U_bᵀ` with `U_b` an integer `n × m_b` matrix (its columns written sparsely) and `Z_b`
either `G_bᵀ G_b / D²` for an integer matrix `G_b` (a **Gram factor**) or a dense rational `m_b × m_b` matrix; and, for
every unknown `K`, nonnegative rationals `λ_K` and `μ_K` — such that the following holds **identically in `y`**, that
is, coefficient by coefficient over the unknowns and in the constant term:

    N − Obj(y)  =  Σ_{matrices}  ⟨Z, A(y)⟩  +  Σ_K λ_K · y_K  +  Σ_K μ_K · (1 − y_K).                         (★)

Here `⟨Z, A⟩ = Σ_{u,w} Z[u,w] A[u,w]`.

**Soundness.** Let `S` be a nonempty independent set of size `s` and put `y = ȳ_S`.

* `⟨Z, A(ȳ_S)⟩ ≥ 0`: `Z` is PSD — `G_bᵀG_b` is PSD for *any* rational `G_b`, a dense block is PSD by the checker's exact
  test, and `U_b Z_b U_bᵀ` is PSD whatever `U_b` is — and `A(ȳ_S)` is PSD (section 2), and the inner product of two
  PSD matrices is nonnegative (write one as `Σ x xᵀ`; the product becomes `Σ xᵀ A x ≥ 0`).
* `λ_K (ȳ_S)_K ≥ 0` and `μ_K (1 − (ȳ_S)_K) ≥ 0`, because the multipliers are nonnegative and `0 ≤ ȳ ≤ 1`.

So the right-hand side of (★) is at least 0 at `y = ȳ_S`, while the left-hand side is `N − s`. Hence

    s ≤ N   for every nonempty independent set S,   and therefore   α ≤ ⌊N⌋.                                ∎

That is the entire argument. (Compared with the triple-level page there is no equation row and no `le_diag` row:
the rows `0 ≤ y ≤ 1` do the work those did, and they make **every** PSD `Z` certifiable, at the explicit cost `Σ μ`.)

## 4. What the checker checks, and what it does not

It checks, in exact rational arithmetic, printing each step:

1. **the plane and the group**, rebuilt from `q` and the modulus alone: the edge list's hash against the file's; every
   **generator** of `G₀` verified, as a permutation of the `n` points, to fix 0, be a bijection, be additive (`g(a + b)
   = g(a) + g(b)` for every `b` and every `a` on the two axes, which generate `V`) and preserve the unit circle; the
   closure under composition;
2. **the unknowns and the multipliers**: the file's list of canonical forms is well-formed and sorted, and every `λ_K`,
   `μ_K` is `≥ 0`;
3. **positive semidefiniteness**: a Gram-factor block needs no test; a dense block is tested by exact `LDLᵀ` (every
   pivot `≥ 0`, and a zero pivot's row zero);
4. **every coefficient of (★)**: for each matrix, the canonical form of every set `anchors ∪ {u, w}` the entries touch
   (by the construction in section 2, which only ever outputs a `g(T − t)`); the file's list of unknowns must be
   *exactly* the forms met; then `⟨Z, A(y)⟩` is accumulated as integer numerators over one denominator;
5. **(★) coefficient by coefficient**, and `N` recomputed from its constant term, `N = 1 + (constant of Σ⟨Z, A⟩) + Σ_K
   μ_K`, which must equal the file's `N` exactly; `⌊N⌋` must equal the file's `alpha_bound`.

It does **not** check sections 1–3; that is what this page is for, and they are hand-checkable.

**What it trusts.** Python's integers and `fractions.Fraction`; the JSON parser's reading of integers and strings (a
float anywhere a number belongs is refused by name); and, from `tools/fplane_cert_check.py` (also standard library),
the field `𝔽_q` built from the modulus — whose irreducibility that file proves by trial division — the edge hash, the
rational reader and the `LDLᵀ`. The plane it builds hashes to `b15ae514…7ff3d` at `q = 27`, which is also the hash an
independent implementation of `𝔽₂₇` (`tools/fplane.py`, `graph_q27`) gives, and the hash of every other record of this
plane in the repository.

**Not on the trust surface.** The columns `U_b` (any integer matrix is sound); the Gram factors (any rational matrix is
sound); the producer and the solver; the file's numbering of the unknowns (compared against the rebuild, never read as
a fact). A wrong `U_b` or a badly rounded `G_b` can only produce a weak certificate, never a false one.

**Two implementation facts the checker relies on, both immediate.** (i) `A(y)[u, w]` and `A(y)[w, u]` are the same
affine form (the sets are equal), so the checker folds `Z[u,w] + Z[w,u]` onto `u ≤ w`. (ii) To look up the set
`{a} ∪ {u, w}` it forms the canonical form of `{0, u − a, w − a}`, and for `{a₁, a₂} ∪ {u, w}` that of
`{0, a₂ − a₁, u − a₁, w − a₁}`: the result is still `γ(T)` for some `γ ∈ Γ` (compose with the translation), so the
property section 2 needs is untouched.

## 5. How the file was made — for the curious only

1. A floating-point first-order method (the arrowhead ADMM of `tools/fs54_d4_quad.py` on the dual) produces an iterate;
   the producer copies the solver's checkpoint and records its sha256 and iteration count.
2. The iterate is projected onto the PSD cone block by block. The solver's blocks are **character blocks**: for a small
   group `H` of involutions fixing the anchor set (`{±I, ±reflection}` for the one-anchor matrices; for anchors `{0, d}`
   the reflection fixing `d` and, when the signs agree, `z ↦ d − z`) and a character `χ`, the block's rows are
   `H`-orbit representatives `r_i` with stabiliser sizes `st_i`, and its entries are
   `Σ_h χ(h) A[r_i, h r_j] / √(st_i st_j)`.
3. Each projected block `Z_solver` is factored `G = diag(√λ) Vᵀ` over its eigenvalues above `10⁻¹⁰` of the largest,
   and moved to the checker's presentation: the columns become the signed orbit sums `c_i = Σ_{w ∈ H r_i} χ(h_w) e_w`
   (integers ±1), and — because the checker pairs `Z'` with `A` as `Σ Z'[i,j] Σ_{w,w'} c_i[w] c_j[w'] A[w,w']`, which by
   the `H`-invariance of `A` as a function of the canonical forms equals `|H| Σ_g χ(g) A[r_i, g r_j] / (st_i st_j)` — the
   factor is multiplied by `diag(√(st_i / |H|))`. That diagonal holds `√2`, which is why it is folded into `G` *before*
   the rounding rather than written as a rational `U`. `G` is then rounded to integers over `D = 10⁸`.
4. With `Z` fixed, the multipliers that make (★) hold and minimise `N` are **determined**: writing `a_K` for the
   coefficient of `y_K` in `Obj(y) + Σ⟨Z, A(y)⟩`, take `μ_K = max(0, a_K)`, `λ_K = max(0, −a_K)` and
   `N = 1 + (constant of Σ⟨Z, A⟩) + Σ μ_K`. The producer computes these exactly with the checker's own pairing, writes
   the file, and runs the checker on it in a fresh process.
5. **A second implementation as a control.** The rounded factors are also scored in floating point through the
   solver's own constraint matrix (built by `fs54_d4_quad`, which shares no code with the checker's pairing). At
   `q = 27` the float score is `141.593344529` and the exact `N` is `141.593344530`, a difference of `4.5·10⁻¹¹`; at
   7 and 11 the differences are `10⁻¹⁴`. A missing entry, a wrong sign or a wrong block map in either implementation
   would show here.

Rounding costs nothing measurable at `D = 10⁸` (the float reading of the unrounded iterate is `141.593347`). **The
cost that remains is `Σ μ = 0.1006`**, the unconverged iterate's dual infeasibility, spread thin over 71,204 of the
77,238 unknowns — so it is convergence, not rounding precision, that buys a lower `N` here.
