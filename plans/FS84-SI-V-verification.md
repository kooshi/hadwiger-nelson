### 1.2 Readings — every term fixed

Throughout, `F` is a real number field, `L = F(i)`, `U = U_F = {z ∈ L : z z̄ = 1}` (the unit vectors; equal to the norm-one torus `T(F)` of
`L/F`), `R = ℤ[U]` (the additive span of `U`, a ring since `U` is a multiplicative group), `R̂ = Hom(R, ℝ/ℤ)` compact. A **character** is
written additively, `θ ∈ R̂`, and `χ(x) = e(θ(x))`. `U` acts on `R̂` by `(u·θ)(x) = θ(ux)`.

- **R1 (random colouring).** `μ` is a Borel probability on `X₄(F) ⊂ {0,1,2,3}^R`, the proper four-colourings of `Cay(R, U)`, invariant
  under the shifts `T_y c = c(· + y)`, `y ∈ R`. `U_y f = f ∘ T_y` on `L²(μ)`.
- **R2 (trace spectral measure).** `e₀, …, e₃ ∈ ℝ³` the vertices of a regular tetrahedron, `|e_j| = 1`, `⟨e_j, e_k⟩ = −1/3` (`j ≠ k`),
  `Σ e_j = 0`; `g(x) = e_{c(x)}`; `g_k` the `k`-th coordinate of `g(0)`, a function in `L²(μ)`. `σ_μ = Σ_{k=1}^{3} σ_{g_k}`, where
  `⟨U_y g_k, g_k⟩ = ∫ χ(y) dσ_{g_k}`. So `σ̂_μ(y) = E⟨g(0), g(y)⟩ = 1 − (4/3)P(c(0) ≠ c(y))`: a probability measure, symmetric
  (`g` is real), with `σ̂_μ(u) = −1/3` for every `u ∈ U`. **Uncentred**; the centred version differs by an atom at the trivial character,
  which lies in `T ⊆ E_S`, so every integral over `R̂ ∖ E_S` below is the same under either reading.
- **R3 (the sets).** `T` = **all** torsion characters of `R` (countable: `χ^m = 1` factors through `R/mR`, finite by R88-J28V-7).
  `A` = the characters continuous for the archimedean topology on `R ⊂ L ⊗ ℝ` (all complex places of `L`), i.e. `x ↦ λ(x) mod 1` for
  `λ ∈ Hom_ℚ(L, ℝ)` (every ℚ-linear functional extends ℝ-linearly to `L ⊗ ℝ`; this is row 98's `A(R_F)`). `Fin_S` = the characters
  continuous for the topology of `R ⊂ ∏_{v∈S} L_v`, `S` a finite set of split places (`L_v = L ⊗_F F_v ≅ F_v × F_v`). `E_S = T + A + Fin_S`,
  `E = ⋃_S E_S`, both subgroups of `R̂`.
- **R4 (the `E_S`-factor).** `H_S = {f ∈ L²(μ) : σ_f(R̂ ∖ E_S) = 0}` (a closed `U_y`-invariant subspace: the range of the spectral
  projection `P_S = 1_{E_S}` of the Koopman representation). The **`E_S`-factor** `𝒜_S` is the σ-algebra generated by `H_S` (the brief's
  phrase). Stage 2 proves `L²(𝒜_S) = H_S`, so `P_S = E[· | 𝒜_S]`, and the reading is unambiguous. `a_j(x) = P(c(x) = j | 𝒜_S)`, with the
  equivariant version `a(x) = a(0) ∘ T_x`; `supp a(x) = {j : a_j(x) > 0}`.
- **R5 ("carries a translation-equivariant proper four-colouring `c′`").** An `𝒜_S`-measurable map `c′ : X₄ → {0,1,2,3}^R` with
  `c′(x) = c′(0) ∘ T_x` and `c′(x) ≠ c′(x + u)` a.s. for every `x ∈ R`, `u ∈ U`. **The clause "with `c(x) ∈ supp P(c(x) = · | E_S-factor)`
  almost surely" does not mention `c′` and holds for every `μ`** (`P(c(x) ∉ supp a(x)) = E[Σ_{j ∉ supp a(x)} a_j(x)] = 0`). So, as
  written, the right-hand side of (SI)'s "iff" is "the `E_S`-factor carries some proper equivariant `c′`". Stage 2 judges that, and
  records the two nearby readings (`c′(x) ∈ supp a(x)`; `supp a(x) = {c′(x)}`).
- **R6 (A⁺, B⁺).** "Given T-C(A)" = R88-TCA over ℚ(√47) ("no translation-invariant Borel probability on `X₄(F)` has spectral measure carried
  by `T + A + Fin_S`", `S` finite split, dyadic included). "Given T-C" = R88-TC over a type-(B) field ("… carried by `T + A + Fin_S` … is
  carried by Pull"). "Carried by Pull" = `μ(Pull) = 1`.
- **R7 (R-U, SP).** "finite measure" = finite **positive** Borel measure (the standard meaning; SP's left side says "positive"
  explicitly). The literal signed reading is recorded where it changes a verdict. "multiple of Haar" includes `0·Haar`.
- **R8 (control).** A four-colouring `γ` of the plane at 7 (`Γ₇`, at a stable place `𝔭 | 7` of ℚ(√11), residue field `𝔽₄₉`), pulled back
  along `π : R → 𝔽₄₉` with a uniform random translate `t ∈ 𝔽₄₉`; each point `x` whose closed neighbourhood misses a colour ("gapped") is
  recoloured, **conditionally independently given `t`**, uniformly from its available set `A(x)` (the colours absent from its
  neighbourhood, together with its own). The control presupposes that the result is a.s. proper (else it is not a point of `X₄`); stage 2
  uses exactly that.
- **R9 (W1).** "There is no pair `(θ, W)`, `θ ∈ R̂`, `W` Lebesgue measurable, such that `c_t` is a proper four-colouring for a.e. `t`."
  `Θ_k(R_F) = {θ : θ(U) ⊆ [1/k, 1 − 1/k] + ℤ}` (FS-86 Notation for `k = 4`; FS-91's `Θ_k`). Row 98's field clause: `Θ_k(R_F) ⊆ T + A(R_F)`
  for every `F ⊆ ℝ` and every `k ≥ 2`.
