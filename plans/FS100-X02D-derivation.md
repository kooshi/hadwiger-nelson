### 1.2 EL2021, read (G50: reading status per section)

- **§1 (pp. 1–5): read in full, 2026-09-26, X02D.** Definitions, verbatim (p. 2): "a solenoid X is a compact, connected, abelian group whose
  Pontryagin dual X̂ can be embedded into a finite-dimensional vector space over Q"; "A Z^d-action α by automorphisms of a solenoid X is called
  irreducible if there is no proper infinite closed subgroup which is invariant under α, and totally irreducible if there is no finite index
  subgroup Λ ⊆ Z^d and no proper infinite closed subgroup Y ⊆ X which is invariant under the induced action α_Λ. A Z^d-action is virtually
  cyclic if there exists n ∈ Z^d such that for every element m ∈ Λ of a finite index subgroup Λ ⊆ Z^d there exists some k ∈ Z with
  α^m = α^{kn}."
- **Thm 1.2, verbatim (p. 2):** "Theorem 1.2. [7, Thm. 1.1] Let α be a totally irreducible, not virtually-cyclic Z^d-action by automorphisms
  of a solenoid X. Let µ be an α-invariant and ergodic probability measure. Then either µ = m_X is the Haar measure of X, or the entropy
  h_µ(α^n) = 0 vanishes for all n ∈ Z^d."

  virtually cyclic factors" is Thm 1.3's hypothesis (the term "virtually cyclic factor" is used, not defined, in §1; the definition of
  virtually cyclic is the one quoted).

### 1.4 The obligation-modeling pass on PE-2 (the skill invoked fresh at 05:52)

*The statement from which the proof derives.* PE-2 is a decomposition statement about arbitrary `U`-invariant `τ`; no argument runs on it
directly. Read the space: the only theorem in hand (EL Thm 1.2) is **ergodic, per acting group `Γ ≅ ℤ²`, per solenoid `M̂`**; `R̂` is the
inverse limit over the directed set of f.g. `ℤ[Γ]`-submodules `M`. So the recursion that carves the space is (i) ergodic decomposition (for `Γ`
on `R̂`), (ii) the directed limit over `M`, and the local obligation is Thm 1.2 on each `M̂`. The statement from which PE-2 derives:

> **Lemma Γ.** *For an admissible `Γ` (two generators, every finite-index subgroup spanning `L` over `ℚ`) and a `Γ`-invariant, `Γ`-ergodic
> probability measure `ρ` on `R̂`: `ρ = m`, or `h_ρ(γ) = 0` for every `γ ∈ Γ`.*

Then: PE-2 = Lemma Γ + (U permutes the `Γ`-ergodic components, since `U` commutes with `Γ`) + (every non-torsion `u` lies in an admissible `Γ`)
+ entropy affine over decompositions. The prove/test/assume partition: **prove** Lemma Γ, the admissibility of some `Γ ∋ u`, and the
decomposition step; **test** (exact arithmetic) PE-1's counterexample; **assume** EL Thm 1.2 [external, in print] and four textbook facts
(named at each use). The weakening move that manufactured Lemma Γ: drop `U` for one `Γ` and put the ergodicity on `Γ`, where the theorem is.
