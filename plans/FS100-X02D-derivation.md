## Stage 2 — SAVED (HX-1, PE-1)

**Lemma F (finiteness)** [hand, textbook]. *A torsion-free abelian group `A` of rank `n` has `|A/mA| ≤ mⁿ` for every `m ≥ 1`.* For a prime `p`,
`dim_{𝔽_p} A/pA ≤ n`: lift `n + 1` classes, take a ℤ-relation, divide it by the largest power of `p` dividing every coefficient (legitimate
since `A` is torsion-free), and reduce mod `p`. Multiplication by `pᵏ` maps `A/pA` onto `pᵏA/pᵏ⁺¹A`, so `|A/pᵉA| ≤ p^{en}`; and
`A/mA ≅ ⊕_p A/p^{v_p(m)}A`. ∎ *Consequence used throughout:* if `M ⊂ L` is a finitely generated module over a ring `S ⊂ L` and `N ⊆ M` is an
`S`-submodule with `ℚN = ℚM`, then `M/N` is finite (it is finitely generated over `S` and torsion, so one integer `m ≥ 1` kills it, and it is
a quotient of `M/mM`).

### 2.1 HX-1 — **TRUE** [hand]

1. Pontryagin duality (`R` discrete, `R̂` compact): closed subgroups `Y ⊆ R̂` correspond to subgroups `N = Y^⊥ ⊆ R`, with `Y = N^⊥ ≅ (R/N)^`;
   and `u·Y ⊆ Y` for all `u ∈ U` iff `uN ⊆ N` for all `u ∈ U` (the action is the dual of multiplication, and `U` is a group). [textbook]
2. `U` is a multiplicative group, so `R = ℤ[U]` is the ℤ-span of `U`; a `U`-stable additive subgroup `N` is therefore an **ideal** of `R`.
3. A nonzero ideal `I` has finite index: for `0 ≠ x ∈ I` take its primitive minimal polynomial `c_d x^d + … + c₁x + c₀` over ℤ; `c₀ ≠ 0` and
   `c₀ = −x(c_d x^{d−1} + … + c₁) ∈ xR ⊆ I`, so `R/I` is a quotient of `R/c₀R`, finite by Lemma F (`R ⊂ L` is torsion-free of rank `[L:ℚ]`).
4. So `Y` is finite if `N ≠ 0`, and `Y = R̂` if `N = 0`. ∎

Nothing about `R` beyond "a subring of a number field" is used — not `R = O′` (row 100). **Remark:** HX-1 says `U` acts irreducibly on
`R̂`; the obstruction in row 118 is only that no *finitely generated* `Γ` does.

### 2.2 PE-1 — **FALSE as written**; the corrected form PE-1′ **TRUE** [hand + tools exact]

**The criterion** [hand]. For `Γ = ⟨u₁, u₂⟩ ⊂ U` with `u₁, u₂` multiplicatively independent (so `ℤ² ≅ Γ` by `(a,b) ↦ u₁ᵃu₂ᵇ`) and `M` as in
PE-1:
- `M̂` is a solenoid (`M ⊂ L` is countable and torsion-free, so `M̂` is compact, metrizable and connected, and `M` embeds in `L ≅ ℚⁿ`); `Γ` acts
  by automorphisms (`γM ⊆ M` and `γ⁻¹M ⊆ M`, so `γM = M`). **True.**
- **Total irreducibility ⟺ `ℚ(Γ′) = L` for every finite-index subgroup `Γ′ ⊆ Γ`.** (⇐) A nonzero `Γ′`-stable `N ⊆ M` has `ℚN` a
  `ℚ[Γ′] = ℚ(Γ′)`-subspace of `L`, hence `ℚN = L`; `M` is finitely generated over `ℤ[Γ′]` (as `ℤ[Γ]` is, by coset representatives of `Γ/Γ′`),
  so `M/N` is finite by Lemma F's consequence, and `N^⊥` is finite. (⇒) If `ℚ(Γ′) = L′ ⊊ L`, then `N = ℤ[Γ′]·x` (`0 ≠ x ∈ M`) is `Γ′`-stable
  with `ℚN = L′x` of dimension `[L′:ℚ] < [L:ℚ]`, so `N^⊥` is a proper, infinite, closed subgroup invariant under the induced action.
- **Not virtually cyclic, for any such `Γ`**: `α^m = α^{kn}` on `M ⊂ L` forces equality of the multipliers `γ_m = γ_nᵏ`, so a finite-index
  `Λ ⊆ ℤ²` would map into the cyclic `⟨γ_n⟩`; impossible, `ℤ² → Γ` being an isomorphism. **No virtually cyclic factor** once totally
  irreducible (reading "virtually cyclic factor" — used, not defined, in EL2021 §1 — as a nontrivial algebraic factor on which the induced action
  is virtually cyclic): the kernel of a nontrivial factor is a proper closed invariant subgroup, so finite, so the factor is dual to a
  finite-index `N ⊆ M` with `ℚN = L`, and the same multiplier argument applies.

**PE-1′ (the corrected form)** [hand]. *Call `Γ ⊂ U` **admissible** if it is generated by two multiplicatively independent elements and
`ℚ(Γ′) = L` for every finite-index `Γ′ ⊆ Γ` — in particular if `Γ` contains a `w` with `ℚ(wᵏ) = L` for every `k ≥ 1` (a finite-index `Γ′`
contains `w^{[Γ:Γ′]}`). For admissible `Γ` and `M ⊂ R` a finitely generated `ℤ[Γ]`-submodule with `ℚM = L`: `M̂` is a solenoid, the
`Γ`-action is by automorphisms, totally irreducible, not virtually cyclic and without virtually cyclic factor; so EL2021 Thm 1.2 applies to
every `Γ`-invariant ergodic probability measure on `M̂`.* ∎ by the criterion.

The addendum asked for `Γ` "so that no non-torsion element has a power in a proper subfield of `L`". That stricter form is **not needed** and
**not always available**: total irreducibility needs only admissibility, and a `u` with a power in a proper subfield (the `v` above) lies in no
`Γ` of the strict kind, but does lie in an admissible one:

**Lemma W** [hand; Chebotarev, textbook]. *For every non-torsion `u ∈ U` there is `w ∈ U` with `ℚ(wᵏ) = L` for all `k ≥ 1` and `u, w`
multiplicatively independent; so every non-torsion `u ∈ U` lies in an admissible `Γ = ⟨u, w⟩`.* Proof. Chebotarev (in the Galois closure):
infinitely many rational primes `p` split completely in `L`; take one at which `u` is a unit at every prime above `p`. Let `𝔓 | p`, `h` the
class number of `L`, `(z) = 𝔓ʰ`, `c` the conjugation of `L/F`. Since `e = f = 1` over `p`, the prime `𝔭 = 𝔓 ∩ F` has two primes above it in
`L`: `𝔭O_L = 𝔓·c(𝔓)`, `c(𝔓) ≠ 𝔓`. Put `w = z/c(z)`: `w·c(w) = 1`, so `w ∈ U`; `v_𝔓(w) = h`, `v_{c(𝔓)}(w) = −h`, and 0 at the other primes
above `p`. If `wᵏ ∈ L′ ⊊ L`, let `𝔭′ = 𝔓 ∩ L′`: all `[L:L′] ≥ 2` primes of `L` above `𝔭′` are unramified and carry the same valuation
`kh ≠ 0` of `wᵏ`, so one of them is `𝔔 ≠ 𝔓` with `v_𝔔(wᵏ) = kh ≠ 0`, forcing `𝔔 = c(𝔓)`, where the valuation is `−kh ≠ kh`: contradiction.
Independence: `uᵃwᵇ = 1` gives `bh = 0` at `𝔓`, then `uᵃ = 1`, so `a = 0`. ∎

**Answer to the addendum's last question:** yes — every non-torsion `u ∈ U` lies in an admissible `Γ` (Lemma W), so PE-2 needs no separate
argument for `u` with a power in a proper subfield; torsion `u` has `h_μ(u) = 0` for every `μ` (as `h(uᵏ) = k·h(u)` and `uᵏ = 1`).
