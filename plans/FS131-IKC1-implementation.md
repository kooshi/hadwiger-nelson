### 1.4 A statement defect: `sum_le_of_certOK` is false at the present checker

`segAll C` checks the segments `0 … nseg − 1`, and nothing checks that an op's slot lies in one of them: an op whose slot is
in segment `nseg` or beyond is skipped by every segment. `cert3drop` (`data/fs131/ikc1/lean/controls/Drop3.lean`, made by
`tools/fs131_ikc1_gen.py --corrupt dropclass` from `proto-cert-p3.json`) is `cert3` with `U_num = 0` and the stream entries
of the two ops of the constant class pointed at slot 64, which no segment owns (`nseg = 1`). The kernel proves
`certOK cert3drop = true` (`decide +kernel`, under a second), and then `not_sum_le_of_certOK`: the statement of
`sum_le_of_certOK`, quantified over certificates, is false — `φ` the indicator of the origin is in the region (`q = 0`,
`qform_indicator`) and `Σφ = 1 > 0 = U_num/L`. Axioms: `[propext, Classical.choice, Quot.sound]`. Reported to the
coordinator at once (2026-10-14).

Three more places where the checker does not check what its soundness needs, found by reading it against the proof
(not refuted concretely):
* **dimensions** — phase 1 reads a times-1 block's `R` stream as rows of length `|reps|`, the PSD check as rows of
  length `m − 1`; nothing checks `m = |reps| + 1`, nor `m ≥ 2` for a times-q block (whose identity reads `R₀₀, R₀₁, R₁₁`);
* **monomial size** — key injectivity holds for multisets of boundedly many points; nothing bounds the length of
  `reps` or of the orbit representatives;
* **the PSD arithmetic** — the Kronecker digit is the dot product only when no digit carries (the `M` digits small
  against `wB`), and the column accumulator only when `m < 256`; neither is checked.

The remedy is the brief's: `certOK` is restructured and gains these checks (each listed in § 2), and the two theorems'
conclusions stay as they are.

### 2.1 Every change to `certOK`, beside the step of the soundness proof that needs it

`Arith/FibreCert` is rewritten (`certOK C := globalOK C && segAll C && psdAll C`). The conclusions of

| change | the step that needs it |
|---|---|
| every op of non-zero value checks `fSeg < nseg` (in every segment), and `globalOK` checks `nseg > 0` | K2i: the per-segment sums add up to the whole identity only if every op lands in a checked segment (§ 1.4's counterexample) |
| the op's monomial has at most seven points (`lenU a + lenU b < 8`); phase 1 checks the same of `g A0`, `g A1`, `a_i`, `a_j` | K2d: the base-8 digits of `Σ 8^x` are the multiplicities only while each is below 8 |
| bag key `Σ 8^x` replaces the power-sum key | K2d without Newton's identities: the digit lemma that serves the slots serves the key |
| every times-1 block has `m = |reps| + 1`, every times-q block `m ≥ 2` | K2g: the identity reads `R` at indices below `m` only, so the matrix it reads is the one the PSD check certifies |
| `R` is decoded once (`Blk.tri`) and every check reads that copy (`triGet`, `Blk.pairCoefs`, `symRows`) | K2a: no reader semantics is needed — each value read is used once, consistently |
| phase 1's orbit row index checked present (`bmem`); the q-part's class index checked below `|tnu|` | K2h: a term routed to a missing row or class was dropped in silence |
| every weight index below `|weights|` | K2g: `c`, `σ` and `κ` are read from one weight; out of range, `κ` came from a default the others did not |
| PSD: every digit of a packed row of `M` below `2^wm`, each row below `2^(wB(m+1))`, `(m+1)·4^wm < 2^wB`; `E` computed row by row over the full symmetric rows (each Kronecker product twice; no column accumulator) | K2b/K2g: the Kronecker digit is the dot product only when nothing carries |
| the key mismatch is a verdict (`opGood`), not a poison bit in the leaf | K2c: the leaf invariant has no poison term |
| phase 1's packed orbit rows are certificate literals (`orows`), checked equal once (`orowsOK`), read by every segment | none: cost (each segment repeated 3.7 GB of phase 1) |
| `κ`'s table a list (`wtab`), not 160-bit packed fields | K2g: a packed field could overflow, unchecked |
| the rows' box expansion recursive in `B` (`boxOps`) | K2f: `Π(1 − φ)` by induction, no mask arithmetic |

## Stage 3 — SAVED: the proof's skeleton; the assembly, level one, the left side and the rows

`Arith/FibreCertSound`: the moments `Ym p φ m = Σ_{γ ∈ affs p} Π_{x ∈ m} φ(act γ (pt p x))`, summed (unnormalised) over
the maps `act (t, s, e) z = s·z̄^e + t`, `N(s) = 1`; an op's value `opVal`; `opSum` of a list of ops. The theorem is
assembled from five children: `opSum_eq_zero` (the computation half), `opSum_O1` (the left side: `−U_num·G + L·G·Σφ`,
`G = |affs|`), `opSum_O23_nonneg`, `opSum_O4_nonneg`, `opSum_O5_nonneg`; then `L·G·Σφ ≤ U_num·G` and `G, L > 0`.
`card_le_of_certOK` follows from it (the indicator of an independent set has `q = 0`). Proved at this stage: the
assembly, `card_le_of_certOK`, `opSum_O1`, the rows (`opSum_boxOps`: `±lam·Σ_γ Π_A φγ·Π_B(1 − φγ)`, by induction
on `B`).

## Stage 4 — SAVED: the computation half proved

`opSum_eq_zero : certOK C = true → opSum (opList C (orbRows C) (qcoefs C)) = 0`, with no `sorry`, from:
* `sum_digit` — digit `e` of `Σ_{i<K} c_i B^i` is `c_e` when every `c_i < B` (K2b); `digits_eq` its use on the slots;

### `LEAN.md` § The kernel's cost model (after the bullet "A kernel leaf priced from a plan's table is priced high")

- **List recursion on a short list costs the kernel a `brecOn` per step; an unrolled `match` does not.** Computing an
  op's key as `bag ((a ++ b.map f).map g)` (`++`, `map`, `foldl`, `length` on lists of at most four points) cost 51.6 s
  and 4.2 GB at p = 7; the same key as an unrolled `match` on `a` and on `b` (`FibreCert.bagMap`, `lenU`), 26.6 s and
  3.3 GB. A `let` chain in the step is not a cost: removing it changed nothing (FS131-IKC1).
- **Random access into a list of lists is paid per lookup and retained**: `triGet` by `getD` in phase 1 at p = 11
  (1953 pairs × 11 blocks) cost 35 s and 6.3 GB alone; the same entries read in order from the flattened rows,
  nothing measurable. An in-place `List.modify` of a 218-element list per pair cost 1.6 GB; buckets of 16 removed it
  (FS131-IKC1).
- **A computation every declaration repeats belongs in the data, checked once**: phase 1's packed orbit rows as
  certificate literals, compared in one declaration (`orowsOK`), took a segment at p = 11 from over 12 GiB to 9.5 GB
  (FS131-IKC1).
