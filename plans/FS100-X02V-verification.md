### 2.1 HX-1 — TRUE [hand]

Pontryagin duality: `H ↦ H^⊥ = {x ∈ R : χ(x) = 1 ∀χ ∈ H}` is a bijection from closed subgroups of `R̂` to subgroups of `R`, with
`H = (H^⊥)^⊥ ≅ (R/H^⊥)^`. `H` is `U`-invariant iff `H^⊥` is: if `x ∈ H^⊥`, `χ ∈ H`, then `χ(ux) = (u·χ)(x) = 1`, so `ux ∈ H^⊥`; conversely if
`uH^⊥ ⊆ H^⊥` then `(u·χ)(x) = χ(ux) = 1` for `x ∈ H^⊥`, so `u·χ ∈ (H^⊥)^⊥ = H`. A `U`-stable additive subgroup is a `ℤ[U] = R`-submodule,
i.e. an ideal `I`. `I = 0` gives `H = R̂`. `I ≠ 0` gives `H ≅ (R/I)^`, finite, because every non-zero ideal of `R` has finite index — from
`R = O′` Dedekind with finite residue rings at its maximal ideals (the stable primes), or with no input at all from `[LevitzMott1972]` Thm 2.3
(every subring of a number field has every non-zero ideal of finite index; by statement, as recorded in `BIBLIOGRAPHY.md`, not re-read here).
The control behaves as expected.

### 2.3 PE-2 (PE-lim) — TRUE [hand, one mind; on EL2021 Thm 1.2 by statement]

*Entropy facts used.* (J) Jacobs: for a `u`-invariant `μ = ∫ μ_ξ dP(ξ)` with each `μ_ξ` a `u`-invariant probability, `h_μ(u) = ∫ h_{μ_ξ}(u) dP`
(compose the given decomposition with each `μ_ξ`'s `u`-ergodic decomposition — by uniqueness this is `μ`'s `u`-ergodic decomposition — and
apply Jacobs's theorem twice). (K) For a `u`-equivariant factor `π`, `h_{π_*μ}(u) ≤ h_μ(u)`; for an increasing sequence of `u`-invariant factor
σ-algebras generating the whole, `h_μ(u) = lim` of the factor entropies. (H) Lemma H.

**Step 1 — reduction to `U`-ergodic measures.** `U` is countable and `R̂` compact metrizable, so a `U`-invariant finite positive `τ` has an
ergodic decomposition `τ = ∫ τ_ξ dP(ξ)` into `U`-ergodic probabilities. Put `a = P{ξ : τ_ξ = m}` and `τ′ = ∫_{τ_ξ ≠ m} τ_ξ dP`: then
`τ = a·m + τ′`, `τ′` is `U`-invariant, finite and positive, and by (J) `h_{τ′}(u) = ∫_{τ_ξ ≠ m} h_{τ_ξ}(u) dP` for every `u`. So PE-2 follows
from

> **PE-erg.** A `U`-ergodic probability `τ` on `R̂` with `h_τ(u) > 0` for some `u ∈ U` is `m`.

(A torsion `u` has `h = 0` for every measure, so the `u` in PE-erg is of infinite order.)

**Step 2 — proof of PE-erg.** Fix `u` of infinite order with `h_τ(u) > 0`. Lemma W gives `Γ = ⟨u, w⟩ ≅ ℤ²` with (★). Enumerate
`R = {r₁, r₂, …}` and put `M_j = ℤ[Γ]·{1, r₁, …, r_j}`: finitely generated `ℤ[Γ]`-modules, increasing, `ℚM_j = L`, `⋃ M_j = R`. Let
`π_j : R̂ → M̂_j` be restriction and `τ_j = (π_j)_*τ`; `π_j` is `Γ`-equivariant, so `τ_j` is `Γ`-invariant — **but not in general
`Γ`-ergodic, whether or not `τ` is `U`-ergodic.** So: take `τ_j`'s `Γ`-ergodic decomposition `τ_j = ∫ ν_η dQ_j(η)`. By PE-1′ the `Γ`-action
on `M̂_j` satisfies EL2021 Thm 1.2's hypotheses, so each `ν_η` is `m_j := m_{M̂_j}` or has `h_{ν_η}(γ) = 0` for every `γ ∈ Γ`. Put
`c_j = Q_j{ν_η = m_j}` and `ρ_j = ∫_{ν_η ≠ m_j} ν_η dQ_j`; then `τ_j = c_j m_j + ρ_j` with `h_{ρ_j}(u) = 0` by (J).
- *Uniqueness.* If `c m_j + ρ = c′ m_j + ρ′` with `ρ, ρ′ ≥ 0` of zero `u`-entropy and `c > c′`, then `ρ′ = (c − c′)m_j + ρ` has
  `h_{ρ′}(u) ≥ (c − c′) h_{m_j}(u) > 0` by (H) — impossible. So `c_j` is determined by `τ_j` and `u` alone.
- *Consistency.* `(π_{j,j+1})_* τ_{j+1} = τ_j`, `(π_{j,j+1})_* m_{j+1} = m_j`, and `h_{(π_{j,j+1})_*ρ_{j+1}}(u) ≤ h_{ρ_{j+1}}(u) = 0` by (K). So
  `τ_j = c_{j+1} m_j + (π_{j,j+1})_*ρ_{j+1}` is a decomposition of the same kind, and `c_j = c_{j+1}`. Write `c` for the common value.
- *Positivity.* By (K) some `j₀` has `h_{τ_{j₀}}(u) > 0`; since `h_{τ_{j₀}}(u) = c·h_{m_{j₀}}(u) + 0`, `c > 0`.
- *Extension.* `τ − c·m` is a finite signed measure whose push-forward to every `M̂_j` is `ρ_j ≥ 0`; it is therefore `≥ 0` on the algebra
  `⋃_j π_j^{−1}(Borel M̂_j)`, which generates the Borel σ-algebra of `R̂ = lim← M̂_j`, hence `≥ 0`. It is `U`-invariant.
- *Ergodicity.* `τ = c·m + (τ − c·m)` with both terms `U`-invariant and non-negative; `τ` is extreme among `U`-invariant probabilities, so
  `τ = m`. ∎

**The brief's explicit case** (a `U`-invariant `τ` whose push-forwards are not `Γ`-ergodic): Step 1 removes non-ergodicity for `U`; Step 2
never assumes `τ_j` is `Γ`-ergodic — Thm 1.2 is applied only to the `Γ`-ergodic components `ν_η`, and (J) carries the entropy through the
decomposition in both directions. **Where this could break:** only at Thm 1.2's hypotheses on `(M̂_j, Γ)`, which is why PE-1 as stated (with
`ℚ(Γ) = L` only) is not enough and (★) is needed; Lemma W supplies (★) through every `u`.

### 2.4 CE-1 (conditional MR) — TRUE [hand, one mind]; in fact with `T` in place of `E`

which contains every character with arbitrary components at the places of `S_sp ∖ S_Γ` — **so `Z_Γ ⊄ E` for a single `Γ`**, and Step A alone
does not give MR. (This is the step my C0 named.)

**Step C — countably many `Γ`.** Let `S′_1 ⊆ S′_2 ⊆ …` be finite conjugation-stable sets of split places exhausting `S_sp`. Put
`u_k = ∏ z_𝔓/z̄_𝔓` over one `𝔓` from each conjugate pair in `S′_k` (`(z_𝔓) = 𝔓^h`): `u_k ∈ U` has non-zero valuation at every place of `S′_k`,
so is of infinite order; Lemma W gives `Γ_k = ⟨u_k, w_k⟩` with (★) and `S_{Γ_k} ⊇ S′_k`. By Step A for each `k`, `ν(⋂_k Z_{Γ_k}) = 1`, and by
Step B `⋂_k Z_{Γ_k} = {[y] : y = diag(ℓ), ℓ ∈ L}` (the `ℓ` is `y_∞`, the same for every `k`, and `⋃ S_{Γ_k} = S_sp`), whose characters
`x ↦ ∏_{v stable} ψ_v(Tr ℓx)^{−1}` (product formula) read finitely many stable places at a finite level: **`⋂_k Z_{Γ_k} = T`**. So every
`U`-ergodic `ν ≠ m` has `ν(T) = 1`.

**Step D — MR.** Let `τ` be `U`-invariant, finite, positive, `τ(E) = 0`. Then `τ(T) = 0` (`T ⊆ E`), `T` is countable and `U`-invariant, so in
`τ = ∫ τ_ξ dP` almost every `τ_ξ` has `τ_ξ(T) = 0`, hence `τ_ξ = m`, and `τ = τ(R̂)·m`. ∎ **Stronger than claimed:** (HF) gives "every
`U`-invariant `τ` with `τ(T) = 0` is a multiple of `m`" — the `A` and `Fin_S` layers of `E` are not needed.

### 2.5 FR-1 — TRUE [hand]

If `y = ux` then `yȳ = uū·xx̄ = xx̄`. Conversely, if `x, y ∈ R ∖ {0}` and `xx̄ = yȳ`, then `u = y/x ∈ L` has `uū = 1`, so `u ∈ U` (the
norm-one elements of `L/F`, all of them), and `y = ux`. So the `U`-orbits on `R ∖ {0}` are the non-empty fibres. For the Fourier half, with
`τ̂(x) = ∫ χ(x) dτ(χ)`: `(u_*τ)^(x) = ∫ χ(ux) dτ = τ̂(ux)`, and a finite measure on the compact group `R̂` is determined by its Fourier
coefficients, so `τ` is `U`-invariant iff `τ̂(ux) = τ̂(x)` for all `u, x`, iff `τ̂` is constant on `U`-orbits; `xx̄ = 0` only at `x = 0`. ∎

### 2.6 ED-1 — TRUE for totally real `F`; ill-posed at every real `F` with a complex place [hand + tools exact]

**Scope.** For `F` totally real, `L = F(i)` is CM, `|σ(u)| = 1` at every archimedean embedding, so `H(u) ≤ N` bounds the absolute Weil height
of `u` in a fixed degree and `U_N` is finite (Northcott) and contains 1. **If `F` has a complex place, `U_N` is infinite for every `N ≥ 1`:**
the kernel of `N_{L/F} : O_L^× → O_F^×` has rank `r(L) − r(F) = ([F:ℚ] − 1) − (r₁ + r₂ − 1) = r₂(F) > 0`, and each such unit has `H = 1`.
Checked exactly at `F = ℚ(∛2)`: both fundamental units `ε` of `L` give `u = ε/σ(ε)` with `uσ(u) = 1` and `u⁴ ≠ 1` (`#μ_L = 4`); control
`F = ℚ(√2)` gives only torsion (`tools/x02v_checks.py` C2; plants in `data/fs100/x02v/plants.out`). There `(1/#U_N) Σ` is undefined and the
claim is not a statement.

**Proof for totally real `F`.** Let `τ` be `U`-invariant with `τ(E) = 0`, and `x ∈ R ∖ 0`. By `U`-invariance and FR-1,
`τ̂(x) = (1/#U_N) Σ_{u∈U_N} τ̂(ux) = ∫ (1/#U_N) Σ_{u∈U_N} (x·χ)(u) dτ(χ)`. **Claim: `χ ∉ E ⟹ x·χ ∉ E`.** Multiplication by `x` on `R̂` is
onto with finite kernel `(R/xR)^ ⊆ T`. `E` is carried onto itself: `A` is the image of `Hom_ℚ(L, ℝ)`, on which `x` acts invertibly; a
`Fin_S` character extends continuously to `∏_{v∈S} L_v` (in which `R` is dense, by strong approximation away from an archimedean place), where `x`
acts invertibly; and every `t ∈ T` is `x·t′` with `t′ ∈ T` (a preimage of a torsion point modulo the finite kernel is torsion). So
`E ⊆ x·E`, and `E + T = E`. If `x·χ ∈ E`, write `x·χ = x·e` with `e ∈ E`; then `χ − e ∈ ker ⊆ T` and `χ ∈ E`. So for `τ`-almost every `χ`
the hypothesis gives `(1/#U_N) Σ (x·χ)(u) → 0`, and dominated convergence gives `τ̂(x) = 0` for every `x ≠ 0`: `τ = τ(R̂)·m`. ∎
(Uses nothing about `U_N` but finiteness; the same proof works for any sequence of finite subsets of `U`.)

**Knock-on (not my claim; for the owner):** list X01's EF-G uses the same `H`. At `F = ℚ(∛2)` a non-torsion `u ∈ U ∩ O_L^×` has
`log H(u) = 0` but `h_m(u) > 0` (Lemma H, archimedean terms), so EF-G (a) "for every real number field" fails off totally real `F`, and
EF-G (b) is ill-posed there (`#U_N = ∞`). I have not seen X01's derivations; this is a scope observation from §2's text alone.
