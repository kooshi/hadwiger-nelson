## §1. C1 — the verdicts, derived blind

**Objects, stated exactly before anything is proved.**
- `F ⊆ ℝ` a subfield. Identify `F²` with `F(i) ⊂ ℂ` by `(x, y) ↦ x + iy`; complex conjugation maps `F(i)` to itself because `F ⊆ ℝ`.
  `U_F = {z ∈ F(i) : z z̄ = 1}`, the unit vectors of `F²`.
- **`U_F` is a multiplicative group**: `1 ∈ U_F`, `|zz′| = |z||z′|`, `z⁻¹ = z̄ ∈ U_F`, and `−1 ∈ U_F` so `−U_F = U_F`.
- `R_F = ℤ[U_F]`, the additive subgroup of `F(i)` generated by `U_F`. **It is a ring**: it contains `1`, and the product of two
  finite ℤ-combinations of elements of a multiplicative monoid is again one. **It is the vertex set of the component of 0 in
  `F²`'s unit-distance graph**: a walk from 0 reaches exactly the finite sums `u₁ + ⋯ + u_k` with `u_j ∈ U_F`, and since `−U_F =
  U_F` these are exactly the ℤ-combinations. Every other component is a translate `p + R_F`, so `F²` is `k`-colourable iff the
  Cayley graph `Cay(R_F, U_F)` is. `R_F` is torsion-free (it lies in a ℚ-vector space) and in general not finitely generated.
- `T = ℝ/ℤ`. `Hom(R_F, T)` is given the topology of pointwise convergence; it is a closed subset of the compact product `T^{R_F}`
  (the homomorphism identities are closed conditions), hence **compact** (Tychonoff). The band is the closed set `B = [1/3, 2/3] + ℤ
  ⊂ T`, symmetric under negation. `Θ₃(F) = {θ ∈ Hom(R_F, T) : θ(U_F) ⊆ B}`.
- `R₅ = ℤ[i][1/5]`, `π = 2 + i`, `π̄ = 2 − i`, `5 = ππ̄`, `w = (3 + 4i)/5 = π/π̄` (since `π² = 3 + 4i`), `U₅ = {iᵏwᵐ : k, m ∈ ℤ}`.
  `R₅ ⊆ R_F` for every `F`, because `U₅ ⊂ ℚ(i)` consists of unit vectors with rational coordinates; and `R₅ = ℤ[U₅]`, since
  `w + w̄ − 1 = 1/5`.
- `θ₂ : R₅ → T`, `θ₂(x) = (x mod (1+i))/2`: `(1+i)` is a prime of `ℤ[i]` not above 5, so `R₅/(1+i)R₅ ≅ 𝔽₂`. Every `u ∈ U₅` is
  `≡ 1 (mod 1+i)` (`i ≡ 1`, `w = (3+4i)/5 ≡ 1`), so `θ₂(u) = 1/2`.
- `λ_e(x) = Re(ē x) mod 1` for `e ∈ ℂ`, a character of any additive subgroup of ℂ. On `L = (1/5)ℤ[i]` every character is `λ_μ` for
  `μ ∈ ℂ` modulo the dual lattice `5ℤ[i]`, and `λ_μ(x) = μ₁x₁ + μ₂x₂` (this is FS73-T40's coordinate `μ = (θ(1), θ(i))`).
- **The two levels.** On `R₅` (the field level for the rational pattern), `λ_e` is never torsion unless `e = 0`: `nλ_e = λ_{ne} = 0`
  on `R₅ ⊇ 5^{−k}ℤ[i]` forces `ne ∈ 5^{k}ℤ[i]` for every `k`, so `ne = 0`. On the finite lattice `L` the parity character is itself
  archimedean: `θ₂|_L = λ_{c0}|_L` with `c0 = (5/2)(1 + i)`. Every sentence below says which level it is at.

### §1.1 L1 — χ(F²) ≤ 3 ⟹ Θ₃(F) ≠ ∅. **Verdict: PROVED** (field level, every subfield `F ⊆ ℝ`, no finiteness assumption)

**The finite form used** (named, and re-derived here rather than only cited). *For `Λ` a finitely generated torsion-free abelian group
and `S = −S ⊂ Λ ∖ 0` finite and **generating `Λ`**, a proper 3-colouring of `Cay(Λ, S)` gives `θ ∈ Hom(Λ, T)` with `θ(S) ⊆ B`.* This is
the ⟹ direction of FS73-T22 through FS73-T21's height lift, in T21/T22's own setting (generation assumed; any relation lattice).
It is applied only to `Λ = ⟨S⟩` for a finite symmetric `S ⊂ U_F`, where generation holds by definition, however many relations the
unit vectors in `S` satisfy. (FS73-T42, V2's forward lift, would also cover a non-generating `S`; it is not needed.) The proof, in the
verifier's words, so that the verdict rests on no citation:
1. Choose one generator per ± pair, `S = {±s₁, …, ±s_n}`, `s_i ≠ ±s_j` for `i ≠ j`, and `π : ℤⁿ → Λ`, `e_i ↦ s_i`, surjective, with
   kernel `R` (any subgroup; it is saturated because `Λ` is torsion-free, but that is not used).
2. `c∘π` properly colours the grid `Cay(ℤⁿ, ±e_i)` (an edge `y ~ y + e_i` maps to the edge `π(y) ~ π(y) + s_i`). Lift colour steps to
   heights: `h(y + e_i) − h(y) = ±1 ≡ c(π(y + e_i)) − c(π(y)) (mod 3)` (a proper colour step is `±1 mod 3`). `h` is well defined
   because the grid's cycles are generated by its unit squares, and around a square the four `±1` steps sum to a multiple of 3 in
   `{−4, −2, 0, 2, 4}`, hence to 0.
3. For `ρ ∈ R`, `W(ρ) := h(y + ρ) − h(y)` does not depend on `y`: moving `y` to `y + e_i` changes it by the difference of two `±1`
   lifts of the **same** colour step (`π(y + ρ) = π(y)`), which is 0. So `W : R → ℤ` is a homomorphism, `W(ρ) ≡ 0 (mod 3)` (both
   ends have the same colour), `|W(ρ)| ≤ ‖ρ‖₁` (a path of `‖ρ‖₁` unit steps), and `W(ρ) ≡ ‖ρ‖₁ ≡ Σρ_i (mod 2)` (a sum of `‖ρ‖₁`
   terms `±1`).
4. `W` extends ℚ-linearly to `R ⊗ ℚ` with `|W(x)| ≤ ‖x‖₁` (scale), then by continuity to the real span of `R`, then by Hahn–Banach
   for the ℓ¹ norm to all of ℝⁿ: some `a ∈ ℝⁿ` has `a·ρ = W(ρ)` on `R` and `|a·x| ≤ ‖x‖₁` everywhere, i.e. `a ∈ [−1, 1]ⁿ`.
5. Put `t = (1/2)𝟙 − a/6 ∈ [1/3, 2/3]ⁿ`. For `ρ ∈ R`, `t·ρ = (Σρ_i)/2 − W(ρ)/6 = (Σρ_i − W(ρ)/3)/2`, and `W(ρ)/3 ≡ W(ρ) ≡ Σρ_i (mod 2)`,
   so `t·ρ ∈ ℤ`. Hence `y ↦ t·y mod 1` kills `R` and descends to `θ ∈ Hom(Λ, T)` with `θ(s_i) = t_i ∈ [1/3, 2/3]` and
   `θ(−s_i) = −t_i ∈ B`. ∎ (The parity of step 3 is what lets the band be `[1/3, 2/3]` rather than `[−1/3, 1/3]`; without the shift by
   `𝟙/2` the construction would fail, e.g. on `Cay(ℤ, {±1, ±3})`, whose fibre `{(t, 3t) : |t| ≤ 1/3}` contains no cube vertex while
   `θ = 1/2` colours it.)

**The compactness step, indexed by finite symmetric subsets of `U_F`.** Let `c` be a proper 3-colouring of `F²`; restrict it to `R_F`.
For each finite `S ⊂ U_F` with `S = −S` let `K_S = {θ ∈ Hom(R_F, T) : θ(S) ⊆ B}`.
- `K_S` is closed: it is the intersection over `s ∈ S` of preimages of the closed set `B` under the continuous evaluation `θ ↦ θ(s)`.
- `K_S ≠ ∅`: `c` restricted to `⟨S⟩` properly colours `Cay(⟨S⟩, S)` (a spanning subgraph of the unit-distance graph on `⟨S⟩`); `⟨S⟩`
  is finitely generated and torsion-free; the finite form gives `θ_S ∈ Hom(⟨S⟩, T)` with `θ_S(S) ⊆ B`; and `T` is divisible, hence an
  injective ℤ-module, so `θ_S` extends to `R_F`.
- The family has the finite intersection property: `K_{S₁} ∩ ⋯ ∩ K_{S_r} ⊇ K_{S₁ ∪ ⋯ ∪ S_r} ≠ ∅`.
- `Hom(R_F, T)` is compact, so `⋂_S K_S ≠ ∅`; any `θ` in it has `θ(u) ∈ B` for every `u ∈ U_F` (take `S = {±u}`). So `Θ₃(F) ≠ ∅`. ∎

No finite generation of `R_F` is used (the index set is all finite symmetric subsets, and `Hom(R_F, T)` is compact for any discrete
`R_F`). The finite form needs its `Λ` finitely generated and torsion-free, which `⟨S⟩` is. **Scope:** field level, every subfield of ℝ.
The converse (`Θ₃(F) ≠ ∅ ⟹ χ(F²) ≤ 3`, by `x ↦ ⌊3{θ(x)}⌋` on `R_F` and translates) is immediate and is not used by F-T4.
