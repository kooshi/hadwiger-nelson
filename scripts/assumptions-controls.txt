# The assumptions gate's controls (FS131-T5, 2026-10-06) — read by `./scripts/assumptions.sh --self-test`.
#
# Every control below is planted into ONE copy of the shipped `scripts/Assumptions.lean`: the lines of its
# `## lean` sections go before the `planted` list, the lines of its `## entry` sections into that list (one entry
# per line), its `## ledger` rows into a copy of the ledger. The copy is elaborated once, beside the shipped list,
# and judged by the gate's own `check_receipt` against control records — the real ones plus `[Planted2026]`,
# ledger row 99999, `G99999`, `FS-99999` and the entry id `T5C-ENTRY-1`.
#
# Directives: `## control <name> — <why>`; `## lean`; `## entry`; `## ledger <row>`;
# `## expect FAIL <kind> <culprit>` (a FAIL row of that kind whose culprit, its third field, is exactly that);
# `## expect CLEAN <culprit>` (no FAIL row names it, nor a site of it: the silent partner);
# `## expect ROW <text>` / `## expect NOROW <text>` (some / no row of the output contains the text).
# The self-test is two-sided: every FAIL row that names a planted name must be predicted by an `expect FAIL`
# line here. Planted names start `t5c_`; planted labels start `T5c`. Lines starting `# ` are comments.
