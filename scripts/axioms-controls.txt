# Each block below is planted into a COPY of the shipped `scripts/Axioms.lean`: the lines after `## at <SECTION>`
# go immediately before that section closes (PRE: before the first banner), the copy is elaborated, and the gate's
# own `check_receipt` judges it. Every check the gate makes has a control here that must make it fire, and the
# PASS controls are the partners showing a refusal comes from the plant, not the scaffolding.
#
# Directives: `## control <name>`; `## expect PASS | FAIL <kind> <culprit> | NOFAIL <kind> | ELAB <text> |
# COUNT <key>=<value>`; `## arch <name>` (a row naming <name> in backticks, added to a copy of ARCHITECTURE.md
# § Trust); `## drop-banner <SECTION>`; `## drop-output <prefix>` (delete the first output line with that prefix,
# after elaboration); `## digest <variant> <exit> <text>` (run `scripts/gate_report.py axioms` on this control's
# output against a one-section CLAUDE.md whose Trust ledger sentence is <variant> — `new`, the sentence with the
# right counts; `off`, its imported count one too high; `old`, the form without an imported count; `doubled`, the
# right sentence twice — and expect that exit status and <text> in its output); `## at PRE|CLEAN|PURCHASED|IMPORTED`.
# The audit's order is IMPORTED, CLEAN, PURCHASED, so every planted declaration goes under PRE, ahead of the
# `declareImport` and `#print axioms` lines that use it. Lines starting with `# ` outside a block are comments.
# Planted names start `t3c_`.
